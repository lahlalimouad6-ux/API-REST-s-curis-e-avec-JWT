# Captures d'écran

Déposez ici les captures prises après le lancement de l'application, par exemple :

- `01-login.png` — requête POST /api/auth/login et réponse contenant le token
- `02-acces-autorise.png` — GET /api/user/profile avec le header Authorization
- `03-acces-refuse.png` — réponse 403 sur /api/admin/dashboard avec un token USER

Ces fichiers sont ensuite référencés dans la section « Captures d'écran » du README.
